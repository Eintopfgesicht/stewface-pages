# STEWFACE Hobby Page Pack

Ultra-minimal GitHub Pages holding page.

## Inhalt

- `index.html`
- `assets/css/style.css`
- `assets/img/background.png`

## Zweck

Nur eine ruhige Platzhalterseite:

- Hintergrundbild
- kurzer Hobby-Hinweis
- kein Menü
- keine Projektseiten
- keine externen Dienste
- keine Tracker
- keine Fonts von außen
- keine Formulare

## Hinweis

Die Seite nutzt `meta name="robots" content="noindex, nofollow"`, damit Suchmaschinen möglichst nicht indexieren. Das ist keine Garantie, aber ein klares Signal.
